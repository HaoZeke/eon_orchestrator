* NEB Orchestrator

Modular Snakemake workflow for automated Nudged Elastic Band (NEB) calculations using eOn with machine learning potentials (PET-MAD-XS).

* Quick Start

#+begin_src bash
# Clone and install
git clone https://github.com/HaoZeke/eon_orchestrator.git
cd eon_orchestrator
pixi install -e eon

# Validate workflow (no eOn needed)
pixi run validate

# Run example (requires eOn)
pixi run -e eon hcn
#+end_src

* Known Limitations

- 2D RMSD landscape plotting disabled (rgpycrumbs API changed)
- 1D energy profiles work correctly
- Requires eOn client for full execution (validation works without)
