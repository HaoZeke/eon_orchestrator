#+title: Alanine Dipeptide Conformational Change
#+date: 2026-03-13

* Overview

Alanine dipeptide (Ace-Ala-Nme) is the canonical benchmark system for studying
conformational transitions in peptides. This example demonstrates the C7eq → C7ax
transition, involving rotation around the phi (φ) and psi (ψ) backbone dihedral angles.

* Why This System Matters

** Benchmark System
Alanine dipeptide is the "hydrogen atom" of peptide conformational studies:
- Small enough for exhaustive sampling (22 atoms)
- Large enough to show realistic peptide behavior
- Well-characterized free energy landscape
- Standard test for enhanced sampling methods

** IRA Alignment Value
The C7eq → C7ax transition involves:
- ~140° rotation in phi angle
- ~110° rotation in psi angle
- Significant backbone reorganization
- Multiple local minima along the path

Without IRA alignment:
- Linear interpolation creates steric clashes
- Initial path may cross high-energy regions
- NEB optimization may converge to wrong saddle

With IRA alignment:
- Correct backbone correspondence identified
- Smooth interpolation in dihedral space
- Realistic initial path for NEB optimization

** Ramachandran Plot

The transition traces a path on the Ramachandran plot:
- C7eq: φ ≈ -80°, ψ ≈ 150° (extended β-region)
- C7ax: φ ≈ 60°, ψ ≈ 40° (α-helical region)
- Path crosses the forbidden region (steric clash)
